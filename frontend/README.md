# EntityMatch AI - Frontend

This directory is reserved for the UI dashboard for EntityMatch AI.

Per current specifications, the full UI is deferred until the ML challenge data and models are active.

## Planned Features:
1. **Candidate Pair Inspector**: Side-by-side visual comparison of matched companies with field-level highlighting.
2. **Threshold Tuning Widget**: Interactive precision-recall & F0.5 slider to visualize trade-offs before generating competition submissions.
3. **Manual Verification & Active Learning Interface**: Quick manual annotation for borderline candidate pairs.
4. **Explainability Visualizer**: Waterfall charts for feature attributions on match decisions.
